# Tratte

Tratte — самостоятельно размещаемый сервис для личного учёта покупок по
электронным чекам. Он читает только настроенные письма с чеками через Gmail API,
сохраняет структурированные покупки в PostgreSQL на сервере пользователя и
показывает статистику через Telegram-бота.

Доступ к Gmail ограничен областью `gmail.readonly`: Tratte не отправляет,
не изменяет и не удаляет письма.
