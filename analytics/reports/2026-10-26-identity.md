## Подтверждение стартового scope

Read-only чтение PostgreSQL воспроизвело восемь кандидатов audit-v1 за
август–сентябрь: 90 строк (43/47). 26.10.2026 пользователь явно подтвердил
трактовку всех восьми вариантов и их количества/содержимого. Варианты остаются
раздельными; весовая quantity используется без повторного умножения.
Личные названия, item_id, решения и спецификации сохранены только в приватном
`.local-evaluations/analytical-identity/`, вне Git и Docker build context.

Проверенный review применён **к временной локальной копии выбранных исходных
строк в памяти**, не к рабочей БД. Получено 8 продуктов, 90 confirmed, 0 rejected,
0 unresolved внутри выбранного scope. Повторное применение вернуло ту же версию;
проверены fingerprint и evidence каждой строки. Чтение источника — транзакция
REPEATABLE READ READ ONLY; записи в production не выполнялись.
Это подтверждение выбранного набора, а не полного покрытия расходов: остальные
item_id остаются unmatched. Исходные данные могут сделать review stale до
применения; apply/validate должны проверить их ещё раз в целевой БД.
